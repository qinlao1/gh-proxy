GitHub 文件加速

优化GitHub文件下载体验，支持release、archive及文件直链加速

使用说明

GitHub文件链接带不带协议头都可以，支持release、archive以及文件，右键复制出来的链接都是符合标准的。

release、archive使用Cloudflare加速，文件会跳转至JsDelivr CDN。

注意：不支持项目文件夹，仅支持具体文件。

更多用法、clone加速请参考这篇文章。

合法输入示例

点击以下示例可直接填入输入框：

  • https://github.com/hunshcn/project/archive/master.zip
  • https://github.com/hunshcn/project/archive/v0.1.0.tar.gz
  • https://github.com/hunshcn/project/releases/download/v0.1.0/example.zip
  • https://github.com/hunshcn/project/blob/master/filename

项目基于Cloudflare Workers，开源于GitHub hunshcn/gh-proxy
